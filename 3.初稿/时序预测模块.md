# 一、ARIMA到底是什么（讲人话 + 能写论文）

ARIMA 本质上就是一句话：

👉 **用“过去的数据”去预测“未来的数据”**

它拆开是三个部分：

- AR（AutoRegressive）自回归 → 用过去值预测现在
- I（Integrated）差分 → 让数据变“稳定”
- MA（Moving Average）移动平均 → 用误差修正预测

------

## 1. ARIMA核心公式（论文必须写）

X_t = c + \sum_{i=1}^{p} \phi_i X_{t-i} + \sum_{j=1}^{q} \theta_j \epsilon_{t-j} + \epsilon_t

解释（你论文可以这么写）：

- (X_t)：当前时刻的挂号量
- (X_{t-i})：历史挂号量
- (\epsilon_t)：随机误差
- (p)：AR阶数
- (q)：MA阶数

👉 再加一个关键点：

如果数据不稳定，需要做差分：

[
Y_t = X_t - X_{t-1}
]

这就是 **d（差分阶数）**

------

## 2. ARIMA适合你的场景吗？

非常适合，因为你的数据：

## 方案一（推荐）：Python做预测 + Java调用

### 1. Python（核心模型）

```python
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA

def predict(data):
    model = ARIMA(data, order=(2,1,2))
    model_fit = model.fit()
    forecast = model_fit.forecast(steps=7)
    return forecast.tolist()
```
