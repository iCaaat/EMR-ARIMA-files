## 二、图表编号和标点格式问题

全篇存在一个系统性格式问题：大量图表编号写成了“图5. 1”“图6. 2”“表2. 1”这种形式，小数点后多了空格。

建议统一为：

图1.1、图2.1、图5.15
表2.1、表6.3
公式（6-7）

目前文中有三种混用：

| 类型     | 文中形式                        | 建议                                 |                    |
| -------- | ------------------------------- | ------------------------------------ | ------------------ |
| 图编号   | 图5. 1、图6. 2                  | 图5.1、图6.2                         | :white_check_mark: |
| 表编号   | 表2. 1、表6. 3，但也有表4.1     | 全部统一为表2.1、表6.3               | :white_check_mark: |
| 公式编号 | “公式2-1”“公式（6-6）”“公式6-7” | 建议统一为“公式（2-1）”“公式（6-7）” | :white_check_mark: |

另外我还发现一个额外风险：导出检查时页脚出现过“第78页，共73页”这类情况，说明页码总页数字段或排版页数可能没有更新。这个虽然不属于内容问题，但定稿前必须在 Word 中全选全文后按 F9 更新域，并重新检查目录页码、正文页码和总页数。

## 五、重复表达和同义反复

全文最大的问题不是错别字，而是“提高、改善、明显、大大、可以、主要、功能模块、数据支持”这类词重复较多。

比较集中的重复类型如下：

| 重复类型                         | 表现                                           | 建议                                                         |
| -------------------------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| “提高/改善/优化”高频重复         | 很多段落连续出现“提高效率、改善体验、优化流程” | 同一段内最多保留一个，其他改为“缩短等待时间”“减少人工环节”“增强协同能力”等具体表达 |
| “大大/极大/很好/明显”过多        | 例如“大大缩短”“极大优化”“很好地改善”           | 学术论文中建议少用程度副词，改为“在一定程度上”“有效”“较好”   |
| “功能模块”重复                   | 第三、四、五章几乎每节都有“功能模块”           | 可交替用“模块”“功能单元”“业务单元”，但不宜过度堆叠           |
| “数据支持/理论基础/参考依据”重复 | 第六章多次出现类似表达                         | 保留关键处即可，避免每段都说“提供支持”                       |
| “该系统/本系统/本文”密集         | 每段开头经常重复                               | 可删去部分主语，直接进入论述                                 |
| “创建起/塑造起/形成起/建立起来”  | 表达比较别扭，也有 AI 降重痕迹                 | 改为“建立”“形成”“构建”即可                                   |
